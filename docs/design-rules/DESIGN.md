# 交互与视觉规则

依据[需求](../requirements.md)与[设计](../design.md)，当前尚无 UI 或确认的视觉主题。Vue 管理界面面向设备、目录、媒体、权限和运维，协议工作台面向报文与时序；不要用诊断细节淹没日常业务流程。

设备在线、媒体可用、安全验证、用户操作结果分开呈现。异步 MQ 命令显示排队、接入接受、协议执行、完成/失败/过期，不把消息投递显示为设备成功。配置编辑后有实际应用版本与回读。

表单覆盖空值、非法值、并发冲突与权限不足；列表支持空/忙/错状态。长任务显示范围、进度、取消及资源清理；多分屏考虑预算与失败恢复。原始签名报文与格式化展示分离，不改写原始证据。

支持键盘、焦点、输入法、可读对比和窗口缩放。应用建立后用真实交互与截图验证，不把静态检查称为用户体验验收；真正需要用户判断的事项进入集中清单。
