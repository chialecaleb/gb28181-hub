# 产品原则

Hub 是可独立部署的国标接入管理平台，第三方互通只使用适用标准协议；不依赖指定虚拟设备、其管理 API 或共享运行时知识服务。

完整功能范围以[需求](../requirements.md)为准。接入与管理独立，标准控制和产品工作流可区分，设备在线、信令成功、媒体可用、安全验证分别显示。不用假应答、禁用认证或 UI 成功提示代替真实结果。

实现涵盖已约定的适用 GB28181 与 GB35114 功能，分阶段交付明确缺项；软件密码实验不等于合规密码产品验收。设备、通道、绑定、会话和观看者分别计数，不偷换容量目标。

用户操作须有资源范围、权限、进度、错误及必要清理；数据迁移、录像与安全介质处理可追溯。正常业务页面只呈现必要信息，诊断工作台提供原文、时序、差异与证据。
