# 路线与验收

完整阶段与目标以[需求](../requirements.md)及[设计](../design.md)的交付章节为准，不另行降低国标、安全、平台或性能要求。当前仅完成文档与开发基础。

首轮工程先核对 Java/Netty/JAIN 公共 API、Spring BOM、MQ 与媒体候选，建立独立 SIP 核心、管理边界、前端及真实测试入口。随后用注册—认证—心跳—目录切片验证字节、状态、MQ 结果与 UI 观测，再扩展媒体、安全、级联与完整产品能力。

每个需求按[追踪格式](traceability.md)关联条款、设计、实现和用例；记录失败路径与清理。正常回复、消息投递、设备完成、媒体成功分别断言。工程检查、双方互通、第三方互通、容量、安全合规与用户体验分别验收。

退出条件：范围内实现存在、真实门禁通过、自审/审查问题闭环、文档一致、成果可恢复。没有应用或环境时标未实现/not-run；需要用户的真实环境与人工检查统一在集中清单，Agent 继续无依赖部分。
